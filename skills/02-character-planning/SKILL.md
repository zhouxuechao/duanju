# 02-character-planning

- 负责 Agent：`StoryAgent`
- 版本：`1.0.0`
- 目标：建立角色身份、关系和长期状态

## 输入

- `storyBible`

## 输出

- `characters`

## 硬规则

- 角色身份锚点跨集保持稳定
- 不可变身份与可变状态分离：年龄段、脸型、五官比例、肤色、发型基础、体型、声线策略不可随镜头变化。
- 每个角色必须记录欲望、恐惧、秘密、关系温度、知识边界、行为习惯和可识别的微表情；状态变化要有集号、原因和后果。
- 每次运行记录 projectId、projectVersion、输入版本和产出版本，旧产出不得覆盖。

## 失败处理

返回结构化 warnings 或 FAILED；可修复失败只创建局部新版本，不改写已锁定资产。
