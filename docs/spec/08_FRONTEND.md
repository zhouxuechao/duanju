# 08 前端设计

## 目标

个人使用：
- 少按钮
- 少配置
- 重点展示作品
- 技术字段默认隐藏

---

## 1. 创作页

输入：
- Idea
- 题材
- 时长
- 集数
- 风格
- 画幅
- 方言

按钮：
- 生成故事
- 确认故事

下面展示：
- Story Bible
- Character Plan
- Episode Plan
- Script

---

## 2. 剧组页

卡片化展示：
- Character
- Character Look
- Location
- Prop
- Voice

人物卡优先展示脸和全身。
技术字段放“高级信息”。

按钮：
- 锁定
- 重做
- 换服装
- 测试视频可用性

---

## 3. 导演台

左侧：
- Scene
- Shot 列表

中间：
- 大尺寸 Storyboard / Keyframe / Video

右侧：
- Shot 核心信息
- 动作
- 运镜
- 情绪
- QC

底部：
- Take 1 / 2 / 3

按钮只保留：
- 重画
- 修改
- 重拍
- 采用

---

## 4. 剪辑台

上：
- 大播放器

下：
- Timeline

轨道：
- Video
- Dialogue
- Ambience
- SFX
- BGM
- Subtitle

按钮：
- 导出预览
- 导出最终
