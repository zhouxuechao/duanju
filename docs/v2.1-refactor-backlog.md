# V2.1 refactor backlog

本轮不执行下列高风险拆分类重构。它们不是 V2.1 验收阻塞项，必须在独立变更中保持行为 100% 不变，并先补齐 characterization tests。

## DirectorContract

当前约 705 行，同时负责 JSON Schema、canonicalize、reconstruct、validation 与 materialization。建议未来内部拆为 `DirectorSchemaFactory`、`DirectorCanonicalizer`、`DirectorValidator`、`DirectorMaterializer`；外部导演契约和 JSON Schema 版本保持不变。

## PromptCompiler

当前约 341 行，继续作为唯一公开 Prompt 入口。未来只允许把内部装配职责下沉到 Image/Video/Voice/Text assembler，业务 Service 和 Provider Adapter 不得重新拥有 Prompt 构造入口。

## ProductionService

当前约 261 行。未来按纯本地生产规则的职责拆分，但不改变 Production SSOT、Timeline SSOT 或 Spring 对外入口。

## ContinuityEngine

当前约 247 行。底层兼容比较已收口到 `ContinuityCompatibilityEvaluator`。未来可按状态继承、Blocking、资产锚点和 ActionState 分解纯函数；不得创建第二套连续性判断系统。

## 准入条件

1. 先为现有输入输出建立 characterization tests。
2. 每次只迁移一个职责，不改持久化结构和业务语义。
3. `ContinuitySingleSourceContractTest` 与 `PromptBoundaryContractTest` 必须持续通过。
4. 不以行数为目标，不在 Live Canary 前进行大规模重构。
