## 修改项

1. 历史 DialogueLine 三轨 typed columns 与 document JSON 安全迁移，保留已有新字段。
2. 连续性比较收口到 `ContinuityCompatibilityEvaluator`；CONTINUOUS 缺必要状态 fail closed。
3. Timeline 音画关联升级到具体 TimelineItem，支持同一 Shot/Take 多次出现与独立 reflow。
4. StoryFactResolver 单次解析批量加载 Fact、Mutation、Knowledge，查询次数由随 Fact 线性增长降为固定 3 次。
5. V17/V19 旧 CHECK constraint 匹配改为精确语义匹配，找不到唯一目标立即失败。
6. ProviderCapability 只允许明确模型 ID，增加静态未验证状态、Live evidence contract 与完整指纹追踪。
7. 图片、连续视频、素材多视图、TTS、LipSync 在付费提交前统一经过 `PaidProviderPreflight`。
8. UNKNOWN 任务禁止重提；原 taskId 可恢复轮询，恢复 Take 记录来源任务，费用使用不可变 POSSIBLY_BILLED 事件。
9. 前端与运行时业务代码不读取旧对白字段；历史兼容只由迁移完成。

## Provider live capability status

`STATIC_UNVERIFIED`。本轮没有执行真实 Provider Canary，也没有根据猜测修改时长、分辨率、比例或参考数量。

显式 Canary 机制要求：

- `RUN_LIVE_PROVIDER_CAPABILITY_CANARY=true`
- `VOLCENGINE_CAPABILITY_EVIDENCE=<真实证据 JSON 路径>`

只有包含完整能力矩阵与真实 provider request ID 的证据通过契约后，才会在 `target/provider-capability-snapshot.json` 生成 `LIVE_VERIFIED` 快照。
